# Runtime do Atlas

`node.exe` (Node.js v24.22.1, Windows x64) é usado para validar e gravar os padrões locais. O Atlas procura este arquivo antes de procurar o Node no PATH do Windows, permitindo abrir o programa normalmente por `Abrir-Atlas.cmd`.

O executável foi copiado do runtime já instalado no computador. A licença e os avisos de terceiros desta versão estão em `LICENSE-node.txt`, obtido de https://github.com/nodejs/node/blob/v24.22.1/LICENSE.

Ao copiar o Atlas para outra pasta, leve também a pasta `runtime`.
